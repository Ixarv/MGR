# FFMPEG
You must also include ffmpeg.exe in the program's folder or else you can't export mp4 videos.
Download 'ffmpeg.exe' from https://www.ffmpeg.org/download.html

# ZENITH 2  ----  [OLD METHOD FOR EXPORTING CSV]
To make a .csv file using Zenith 2, First download Zenith 2 from https://github.com/arduano/Zenith-MIDI/releases/tag/2.1.5
After that, open Zenith 2 and load any MIDI.
Go to "Modules" and set rendering type to "Note Counter"
Go to "Module Settings" and go to "Save Data" and enable "Save frame data to .csv file" and put ur save location there.
Changing the exported vid's fps also changes the csv's fps rate too.
I usually render .csv zenith 2 stuff with an extremely low resolution (like 4 x 4) and empty text on note counter so it renders a bit more faster. The D14YOB video in my 2nd channel used a CSV fps rate of 120. which you should also input 120 in the CSV fps rate in MIDIGraphRenderer.

Note that Zenith 2 is unstable. (zenith 2 might freeze after clicking preview/render for the second time)
